# تنصيب نظام إدارة المخالفات المرورية

نفّذ الملفين بهذا الترتيب على خادم MySQL 8.0.16 أو أحدث — الأول يُنشئ القاعدة وجداولها العشرة، والثاني يملؤها بالبيانات المرجعية:

```
mysql -u root < database_full_schema.sql
mysql -u root < database_seed.sql
```

ثم ضع مجلد `traffic` في جذر خادم الويب وافتح `http://localhost/traffic/frontend/index.html` — وسجّل الدخول بـ`admin@traffic.ly` / `admin123`، وغيّر كلمات المرور الافتراضية قبل أي تشغيل حقيقي.

---

### ملاحظات

- **ملف البذرة لقاعدة جديدة فارغة وحدها.** لا يحوي أمر تفريغ ولا حذف عن قصد؛ فلو نُفِّذ على قاعدة فيها بيانات توقّف عند أول مفتاح رئيسي مكرر بلا أن يمسّ صفاً واحداً.
- **اسم القاعدة مكتوب داخل ملف المخطط** (`traffic_violations_system`). لتنصيبها باسم آخر، غيّره في سطرَي `CREATE DATABASE` و`USE` في الملفين معاً.
- **قيد `chk_vehicle_identifier`** الذي تقوم عليه ميزة تسجيل المركبة برقم الهيكل لا يُنفَّذ فعلياً إلا على MySQL 8.0.16 أو أحدث.
- بيانات الاتصال بالقاعدة في `backend/config/database.php`.

### كلمات المرور الافتراضية

| الحساب | كلمة المرور | الدور |
|---|---|---|
| `admin@traffic.ly` | `admin123` | مدير النظام |
| `dept1@traffic.ly` · `dept2` · `dept3` | `dept123` | مدير قسم |
| `officer1@traffic.ly` … `officer4` | `officer123` | رجل المرور |
| `pay1@traffic.ly` · `pay2` · `pay3` | `pay123` | مركز الدفع |

### ما ينشئه كل ملف

| الملف | المحتوى |
|---|---|
| `database_full_schema.sql` | ١٠ جداول · ١٦ مفتاحاً أجنبياً · ٥ قيود تفرّد · ٧ فهارس صريحة · قيد تحقق واحد — بلا بيانات |
| `database_seed.sql` | ٣ أقسام · ١١ حساباً · ٤ سجلات ضباط · ٢٥ بند دليل مخالفات — بلا بيانات تشغيلية |
